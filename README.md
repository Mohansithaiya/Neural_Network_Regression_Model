# Neural Network Regression Model

A simple **Neural Network Regression** project built with **PyTorch** to learn and predict continuous values from a generated dataset.

The project demonstrates how a neural network can learn a linear relationship between input and output by optimizing its **weights and bias** using **Mean Squared Error (MSE)** and **Stochastic Gradient Descent (SGD)**.

### What's Inside

* Generated dataset with random noise
* PyTorch-based regression model
* Training loss visualization
* Best-fit line visualization
* Prediction on new sample data
* 100 training epochs with SGD optimizer

### Built With

**Python · PyTorch · NumPy · Matplotlib**

### Project Files

The complete implementation, dataset generation, training process, visualizations, and prediction are available in the uploaded project file.

### Outcome

The trained model successfully learns the underlying relationship in the dataset and produces predictions for previously unseen input values.
